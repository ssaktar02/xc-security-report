# Screenshots

Drop PNG screenshots here to illustrate the docs. `docs/USAGE.md` references
these filenames — capture each from the running app (upload
`input/security-audit.sample.json` first so no customer data appears).

| Filename | What to capture | Suggested caption |
|---|---|---|
| `01-landing.png` | App just opened, sidebar uploader visible | "Landing page with the upload sidebar" |
| `02-entitlements.png` | Sidebar entitlement checkboxes | "Set customer entitlements before reviewing" |
| `03-dashboard.png` | Dashboard: score, severity chart, LB table | "Dashboard overview" |
| `04-lb-report.png` | A Load Balancer report with severity/category tabs and a finding expanded (showing edit box + exclude checkbox) | "Per-Load-Balancer report with editable, excludable findings" |
| `05-manual-checklist.png` | Namespace Report manual checklist section | "Manual review checklist" |
| `06-downloads.png` | The HTML / PDF / Word download buttons | "Export options" |

Guidelines:
- **Use the anonymized sample** (`input/security-audit.sample.json`) — never
  screenshot real customer data.
- Keep browser zoom ~100% and crop to the relevant area.
- PNG preferred; keep each file reasonably small (< ~500 KB).
